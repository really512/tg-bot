# 🤖 GingerXYT Mod Bot

Автоматический модератор для Telegram-чата **«чатик gingerxyyyyyt»**.

## 🔥 Возможности

- 👋 Автоматическое приветствие
- 🚨 Автоматические нарушения
- 🌊 Антифлуд
- 📢 Антиспам
- 🔇 Автоматический мут
- 🔨 Автоматический бан
- 📋 Логи владельцу
- 💬 Уведомление нарушителя в ЛС
- 🛡️ Защита администраторов
- ⚠️ Система предупреждений

## ⚙️ Настройка

Переменные окружения:

```text
BOT_TOKEN=токен_бота
OWNER_ID=telegram_id_владельца
```

Токен бота нельзя публиковать в репозитории.

## 📦 Запуск

```bash
pip install -r requirements.txt
python main.py
```

## 🛡️ Требования

Бот должен быть администратором Telegram-чата с правами на удаление сообщений и ограничение участников.
